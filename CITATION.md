# Citing Semaprax

Semaprax is pre-alpha research. Cite the exact repository state and evidence
surface that supports your statement.

## Repository citation

GitHub and compatible reference managers can read `CITATION.cff`. For a stable
technical citation, replace `main` in a document URL with the commit SHA you
inspected and include that SHA in the reference.

Use the project homepage, <https://wavect.io/semaprax/>, for the localized
overview and canonical project identity. Use this repository for code,
specifications, implementation status, limitations, and executable evidence.

Do not cite a roadmap or changelog entry as current implementation evidence.
Do not generalize a
bounded target gate into universal platform support, complete ecosystem
interoperability, model-token savings, production readiness, or security.

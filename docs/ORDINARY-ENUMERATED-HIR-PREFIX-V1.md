# Ordinary enumerated HIR prefix storage v1

Audience: compiler contributors and reviewers.

Status: source candidate; compilation, runtime, physical accounting and current
application qualification pending. This does not promote a completion row.

The private ordinary ActiveBuilder enumerator may move a tail of at least 4,096
observation handles into immutable sequence storage at a genuine multi-suffix
fanout. The original first prefix-clone work debit and split payment occur
first. Tiny, single-suffix, Selected, Oracle, lent-work, lexical, renewal and
merged-state routes retain their existing algorithms. The threshold selects a
storage strategy; it is neither a new admission ceiling nor a quota.

Each path retains its complete owned-source, failure, residual and continuation
state. No paths, duplicate sequences or terminals merge. The existing
ObservationDag layout provides Seq/Cat storage and its prepaid iterative
release frontier; a distinct constructor uses ordinary free work for new
bound/destruction metadata. It never spends the reserved original skeleton
loan. This constructor refuses Alt and borrowed-work ownership. The private
ordinal marker selects representation plumbing only; it grants no semantic
identity, equality, admission, budget or cleanup authority.

Every original clone/extension/materialization event remains in order. Only
absent pointer-vector backing is removed. Node/selector/append/prepend receivers
and real backing are charged before formation on the actual current payer.
The tiny initial gate reuses two scalar results within the existing paid split
frame; a compile-time whole-layout inequality retains all prior split/fusion
roles. Full selector controls precede profile/renewal inspection. New work uses
the existing ordinary work remainder; no quota, forecast, cap or refund changes.

Sorting and comparison reconstruct complete observation contents through paid
forward cursors. They ignore node addresses and marker equality. Both the flat
PLAN route and immutable PLAN-history comparator use content cursors for shared
HIR. Comparison orders only ephemeral proof paths, never runtime cleanup-plan
vectors. Alt is refused rather than silently interpreted as a single sequence.

The complete frozen 36 sequence and comparison bodies are independently compiled
as old controls, and six whole predecessor sources plus their exact inverse are
retained under `docs/evidence/ordinary-hir-prefix-877-v1`. Existing hostile,
physical, source-custody and application owners remain required, including
#856/#858, both original #831 canonical/contract owners and genuine over-limit
refusals. The source-authored new gates live in the existing lib harness under
`cleanup_plan::replay::skeleton_work::enumerated_prefix`.

Sequence-only paid/physical measurements and the full comparator costs are
separate. New cursor work and receiving can outweigh removed copies; no
end-to-end saving, codec/catalog fit, token/turn/cost gain or production support
is established. Actual #808, catalogs and NDJSON outcomes at unchanged limits
and matched application benchmarks remain later qualification.

The complete-fork successor is a separate source candidate under
`ordinary_plan_history/completed_fork`. It preserves the existing 4,096-item
selector and pending PLAN selector. At a real ordinary multi-suffix product it
moves the complete prefix tail once into the existing immutable Seq carrier;
later nested suffixes concatenate through the existing prepaid Seq/Cat factory.
There is no path/state union, threshold substitution, flattened shadow copy or
shared-identity comparison. Public unobserved and funded ordinary callers are
eligible; selected, oracle, lexical, renewal, merged and lent-work receivers keep
the original sequence. An unshared singleton keeps the original receiver too.

constructs PLAN independently, then uses the existing paid complete-content
HIR sort and original immutable PLAN comparator. Every observation, duplicate
path and terminal participates. Flat final histories retain the original final
verifier. New dispatch, validation, node, cursor and finalizer costs are paid on
the same caller, including cold paths and partial Drop; no original work event,
budget, admission ceiling or refusal is waived. The complete immediate-old
sequence remains separately compiled, with exact source inverses and owning
nested/public/funded/physical/hostile controls. These controls are authored, not
executed; the successor has no runtime or application qualification yet.

Audience: compiler contributors and reviewers.

Status: source candidate; compilation, runtime, physical accounting and current
application qualification pending. This does not promote a completion row.

observation handles into immutable sequence storage at a genuine multi-suffix

state. No paths, duplicate sequences or terminals merge. The existing

bound/destruction metadata. It never spends the reserved original skeleton

identity, equality, admission, budget or cleanup authority.

absent pointer-vector backing is removed. Node/selector/append/prepend receivers
and real backing are charged before formation on the actual current payer.

frame; a compile-time whole-layout inequality retains all prior split/fusion
roles. Full selector controls precede profile/renewal inspection. New work uses
the existing ordinary work remainder; no quota, forecast, cap or refund changes.

forward cursors. They ignore node addresses and marker equality. Both the flat
PLAN route and immutable PLAN-history comparator use content cursors for shared
HIR. Comparison orders only ephemeral proof paths, never runtime cleanup-plan

is established. Actual #808, catalogs and NDJSON outcomes at unchanged limits

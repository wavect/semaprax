# v0.7.0 release status

Status: candidate only; no v0.7.0 archive or signed release is published.

Audience: release reviewers, maintainers, and readers checking hosted claims.

The source package version and dated changelog are prepared for v0.7.0. A
versioned release commit must pass main CI, then an annotated tag at that exact
commit must pass every required job in the hosted `release-gate`. The tag and
publication evidence are pending. This page will record the exact commit, run,
asset inventory, and verification only after those steps complete.

The [v0.6.0 gate record](RELEASE-0.6.0-STATUS.md) remains evidence for its own
failed tag runs. Its partial successful jobs do not certify v0.7.0. See the
[release process](RELEASE-PROCESS.md) and
[signing policy](RELEASE-SIGNING-POLICY-V1.md) for the acceptance rules.

Input is one closed JSON object: `version:1`, `mode`, `manifest` string and
`passes`, a list of source arrays containing only `path` and `source` strings.

1 MiB, more than 512 sources/pass or paths above 4096 bytes fail closed. Modes
`semantic`, `cold-project`, `warm-project`, `cold-image`, `warm-image` require one
pass. `cache` requires exactly three explicit packs, enabling baseline, changed
or malformed input, and original/retry behavior. Production profile/admission
and the actual 64 MiB builder bound remain those of the manifest and engine.
No outer allowance is substituted for their real owners.

protocol encode have separate observations. The fixed pointer registry is
excluded instrumentation, not compiler allowance; metrics are actual requested

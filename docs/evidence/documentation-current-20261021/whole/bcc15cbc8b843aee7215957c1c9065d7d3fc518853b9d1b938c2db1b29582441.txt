Source-only correction of the 8ca candidate; no Cargo, Rust tests or binders.

All newly introduced and_then/filter/map/is_some_and callback chains are gone.
Named checked results and matches now have separately listed actual/formal,
Option, scalar and boolean receivers. CHECKED_ARITHMETIC owns the two value
operands at both actual/formal sites and its Option result. The query names six
checked-add sites; the current probe separately names checked-add/mul/sub and
growth-capacity receivers. The direct call separately owns its actual/formal
arguments, Vec Results, original-growth/Option bindings, len method pairs,
payer equality/selected inputs and boolean controls. The production fee remains
the complete literal old inline price plus this exact direct bank, with no
additional runtime fee-helper invocation before payment.

The copy threshold still tests the original ADDITIONAL_CONTROLS backing price,
not the entire new query/direct cost. Every new role is paid independently,
including fallback overhead. No net application benefit or issue closure is
claimed; the actual application comparison remains required.

The existing direct frontier owner now compares every selected actual receipt
boundary and both work failures against an independent sequence of real reserve
and work methods. That oracle never enters the new query or clone producer.
Repeated sticky diagnostics are required to be the exact six-field empty
SPX-H006, separately from the first reason-bearing failure. Explicit constructed
Continue, FunctionReturn and LoopBreak plans compare complete old/current
paths, work, materialization and Drop; LoopLatch must decline the query.
The original two failing tests and all old assertion bodies stay unchanged.

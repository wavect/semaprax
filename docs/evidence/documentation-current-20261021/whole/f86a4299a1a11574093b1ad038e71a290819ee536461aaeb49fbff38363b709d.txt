# Lexical sequencing minimum source checkpoint

Status: source-only implementation; combined execution qualification pending.

The shipping `path_array/sequence_minimum.rs` macro extends the first active
multi-suffix output only after its original owned path, work debit,
materialization, existing capacity control payment and checked capacity C.
It then pays `RECEIVING` before every new selected borrow, iterator length,
helper argument, checked Option or capacity result. This is a conservative
source-control charge, not a measured machine stack allocation.

The held original suffix iterator has S - 1 entries at this point. The pure
helper checks P + (S - 1), the existing path maximum, next power of two D,
D - C and element-layout multiplication. It selects D only if removed backing
covers the complete additional charge. The old C controls remain paid, with no
refund, discount or earlier metadata credit. P=9/S=2 is an intentional paid
false-probe case; authored tests require its unchanged heap and extra charge.
Stopped-first, empty, small, unpaid, single-successor and later outputs retain
their original operations. The general DAG vector reuse and final suffix moves
remain in the complete owning sequence function.

The complete immediate predecessor is compiled in
`sequence_minimum/before.rs`, with fixed normalized function SHA-256
`90dba8e16f69638f6631caec08acdad4e5fef2df778635ae223c38bd0cdf9232`.
An exact source inverse permits only the specialized macro replacement and
independent Main44 test dispatch hook. The separate namespace retains the
complete incoming helper, predecessors, source controls and original assertions.

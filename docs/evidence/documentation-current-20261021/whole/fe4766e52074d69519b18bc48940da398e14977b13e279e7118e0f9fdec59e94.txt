# Retained merge search owner v1 (#881)

Status: isolated source candidate; no compiler, focused runtime, physical gain,
application fit, pin update or closure claim. All existing limits remain fixed.

The path/call merge receivers keep the exact original merge-N work request
before any directory or owner acquisition. Their first DIRECTORY_CONTROLS
request is unchanged. The next original fee-computation primitive acquisition
becomes a literal SearchOwner/primitive-header bank instead of constructing a
SearchComputation and bounded binary-search callback price for every input.
The owned-suffix row receiver adds this same owner bank to its existing header
reservation AFTER prefix grouping and ALL original suffix observation clones
and merge-N work. No new payment call precedes that frontier. The old row clone
bank loses only SearchComputation: the new route does not compute that price.
Every actual observation clone/call/Result/stored observation remains paid.

SearchOwner is one local live object containing low/high/mid/group/position,
found and Ordering fields. It owns no function, key, observation, budget, ledger
or source binding and cannot escape. Two lexical macros perform a standard
half-open binary search and preserve the first-seen group output order with a
separate sorted index vector. These indices never borrow relocatable backing.
All metadata fields, continuations and ordered call commit lists are compared
by the complete previous content comparator. No runtime cleanup vector is
sorted, repaired or normalized. The search contains no binary_search_by
closure or Result<usize,usize>; there is no paid-once flag around those calls.

The query bank pays the actual Vec len boundary and distinct successful-output
order index boundary. Every loop execution, INCLUDING the terminating empty
interval, pays ORDER_INDEX plus its actual path/call/row indexing inventory,
the complete path comparison inventory (call commits separately), and named
scalar operand/result transports BEFORE the condition or new comparison is
formed. The full branch bank is deliberately acquired even on a terminal
iteration and on non-Equal call keys; unused branch receiving is not refunded.
Only the narrow nonrecursive primitive Result<(),Diagnostic> caller frames
are retained by their two sequential lexical sites: success has no owning
payload, a sole terminal owning error returns immediately, and no frame escapes
or overlaps later use. Compound Results, closures and callback transports were
physically eliminated; borrowed/index/cmp payloads still pay on each execution.
The immutable old N-work contract already covers this bounded merge operation;
no extra graph walk, logical event, allowance, credit or compensating debit is
introduced. The different pure comparison schedule is not a CPU-saving claim.

Half-open invariants give low<=high<=order.len(). For a nonempty interval,
low+(high-low)/2 is below high, and mid+1<=high. These arithmetic operations
cannot overflow for any real Vec length; there is no fabricated overflow
Diagnostic or unchecked external owner state. All backing/count overflow and
first physical refusal remain with the existing actual primitive producers.
All member growth, group publication, union, output, original suffix ownership
and prefix-before-suffix destruction code remains unchanged. Vec<View>, clone
Results and other surviving owned-phase controls are retained and charged;
this candidate does not claim to remove the entire owned forwarding cost.
There is no fallback, refund, cap change or zero-overhead/net-benefit guarantee.
Small/all-unique inputs may pay more and must be reported as measured.

Whole immediate #878 merge and owned-sequence/vector bodies and prices are
independently compiled under test-only namespaces with finite method/module
adapters. Complete earlier B-tree and borrowed sequence controls stay unchanged.
New controls compare full languages, ordered commits/multiplicity, original
work, actual owner/query/step/row-header first/last exact/short/floor boundaries,
all six first Diagnostic fields against the unchanged reserve primitive,
empty sticky retry/no new work or allocation and complete Drop. Existing
foreign/destruction/overflow owners remain enabled. The private owner adds no
new function restriction or source-admission route.

The test-only thirteen-category fixed census observes actual reserve_bytes
requests and before/after acquisition on the same concrete ReplayBudget,
function and immutable invocation binding. It never consults a diagnostic
coordinate for admission. Selected charged() is observed directly; an unrelated
ACTIVE ledger is never substituted. Unsupported oracle/unobserved accounts mark
the packet incomplete. Wrong function/budget/invocation observations are refused
from attribution and mark it incomplete; this does not alter real admission.
All counters are checked; overflow marks incomplete without wrap, saturation or
an event-buffer panic. Existing primitive shipping code remains byte-exact;
test instrumentation calls a complete renamed copy, changes no price/work and
cannot replace its first Diagnostic. New actual measured fixtures reconcile
acquisitions with selected charged() and print paid/allocated/highwater/live
through destruction. Until those owners execute there are no new numeric results.

# Shallow nominal type metadata cloning

Audience: compiler contributors and reviewers.

Status: private component evidence; original native-provider and complete current-head CI qualification pending.

The current-head C/C++ package gate refused an 8,224-byte ownership type-copy census cursor. This bounded fast path recognizes only a nominal with exactly one or two immediate cursor-free scalar/type-parameter arguments. Those children own no recursive type backing. It reserves the exact Vec argument backing, then uses the unchanged derived Clone. Shared declaration identities remain shared. It does not set the recursive cursor-paid flag.

Empty nominals retain their original leaf route. Nominal children, callable children, three or more arguments and every deeper type retain the complete original census, its work and depth bounds, allocation payment, first failure and Drop. A later recursive clone still pays its cursor once. This changes no semantic cache, public type, source program, graph limit, native provider allowance or reserved floor.

The existing full predecessor source control now removes exactly the new hook and compares the entire file with its fixed-hash immediate predecessor before running all its original assertions. All original runtime cases remain. New controls cover every scalar/type-parameter leaf in both argument positions, exact/one-short/zero accounts, sticky refusal without allocation, original physical clone/Drop equality and the untouched recursive fallback.

It used current budget code with only diagnostic test callbacks replaced by no-ops and the current allocation observer (excluding its unrelated self-tests). BTree sizing and semantic failure adapters remain uncalled seams. These results prove the bounded copy component, not the complete compiler, original native-provider recovery or hosted CI.

# ASCII-pattern capture source fixtures

These review fixtures accompany the proposed source matcher; they establish no package contract, implementation, or completion gate. `cases.json` records patterns, byte inputs, compile summaries, semantic outcomes, and byte capture spans. Compact descriptors represent extent boundaries without storing large files. Atoms are `{kind, value, min, max}` (`0` literal, `1` any byte, `2` class bitmap); bitmaps use 32 little-bit-order bytes, and captures are half-open atom-index pairs.

`oracle.py` is a separate small parser and exhaustive matcher. It enumerates finite repetition count vectors in lexicographically descending source order, then checks each whole byte input and derives captures from accepted atom counts. Raw printable ASCII is accepted except reserved syntax punctuation; backslash quotes printable punctuation and `\\xHH` denotes a byte. Classes support leading complement, ascending ranges, and a terminal raw hyphen. The oracle reports semantic `matched` or `no_match` separately from malformed syntax and extent/count refusal. Its enumeration cap produces `oracle_inconclusive`; it is not the source engine's work budget.

The existing `while_loops` language harness consumes the `source_differential` cases and compares SEMAPRAX source results with the fixtures' semantic outcomes and capture spans. The selected driver cases use a generous work limit and never assert a precise work count. A work refusal is neither inferred by the oracle nor accepted as a semantic no-match. UTF-8 is intentionally treated as bytes, so a capture may end within a multibyte encoding.

The source matcher cases target byte-matching obligations relevant to the unchanged LogLens qualification; they do not model the CLI's aggregation, formatting, or all 33 historical checks. The frozen qualification remains 33 historical checks plus 16 independent SPEC boundary checks. Its eight boundary-corpus cases produce text and JSON checks, so those 16 checks do not map one-to-one onto matcher cases. This private source corpus does not alter or replace the qualification.

The oracle has not been run for this source-only batch. No engine, specification, plan, benchmark campaign, frozen prompt, or application-specific requirement is changed here.

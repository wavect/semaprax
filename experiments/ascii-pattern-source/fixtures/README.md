# ASCII-pattern capture source fixtures

These are review fixtures for the proposal in `docs/proposals/ASCII-PATTERN-CAPTURES-DRAFT.md`; they do not establish an API, implementation, package contract, or gate. `cases.json` includes source patterns, byte inputs, expected compile summaries, status codes, and byte capture spans. Compact repeat descriptors keep the 1,024/1,025-byte pattern, 65,536/65,537-byte input, and count-boundary examples readable. The normalized atom shape is `{kind, value, min, max}` (`0` literal, `1` any byte, `2` class bitmap); class bitmaps are 32 little-bit-order bytes, and captures are half-open atom-index pairs.

`oracle.py` is an independent, intentionally small parser and exhaustive matcher. For a parsed pattern it enumerates finite repetition count vectors in lexicographically descending source order and accepts only a complete byte-input match. It reports semantic `matched` or `no_match` separately from compile errors and extent/count resource refusals. Its vector cap is an oracle implementation bound, reported as `oracle_inconclusive`; it is not the proposed engine work budget.

The oracle does not predict engine work usage or decide whether a work-limited engine should return a work refusal. That outcome depends on the exact charged traversal and selected `work_limit`, so fixtures label such interpretation as unknown. Matching bytes also does not assert UTF-8 boundaries; the UTF-8 split case deliberately expects a capture ending between bytes of a multibyte character.

Malformed offsets are asserted only where the draft identifies the offending token/EOF directly: bad or truncated `\xHH`, a stacked quantifier, and unsupported alternation. `pending_cases` records malformed class/bound examples whose exact offending offset remains underspecified; these are not parsed or scored by the oracle. The accepted fixture grammar stays within the proposal's stated examples and ordinary alphanumeric, `:`, `=`, `-`, `_`, dot, capture, class, and repetition forms. Reserved punctuation and class-edge escaping remain pending rather than gaining guessed meanings.

To inspect the oracle output later, run `python3 experiments/ascii-pattern-source/fixtures/oracle.py`. This command has not been run for this source-only batch. No source engine, SEMAPRAX project, draft, plan, campaign, or application-specific rule is changed here.
